# 简历筛选系统

基于AI的智能简历筛选系统，支持批量上传、AI分析、人才画像和PDF报告。

## 部署到 Streamlit Cloud

1. 访问 https://streamlit.io/cloud
2. GitHub登录 → New app
3. 选择此仓库，Main file path = app.py
4. Deploy!

## 功能
- ✅ JD管理 - 创建岗位描述
- ✅ 简历上传 - 支持PDF和图片
- ✅ AI分析 - 自动匹配度评分
- ✅ 人才画像 - 自动生成标签
- ✅ 筛选评估 - 标记通过/淘汰
- ✅ PDF报告 - 一键导出

## 技术栈
- Streamlit
- SiliconFlow API (免费AI)
- SQLite
- PDFMiner + ReportLab
